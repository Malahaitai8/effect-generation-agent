# RAG 模块

该模块保存案例数据、schema、召回实现和任务级案例快照规范。

案例库纳入单图驱动、多图驱动和参考视频驱动案例。多图案例可参与 Step 3 跨链路召回与链路判断；当前 MVP 仍只自动执行单图和参考视频链路，多图链路命中后按现有能力边界暂停。召回在 Step 3 执行一次；Step 4 和 Step 6 读取同一任务快照，不重复进行语义召回。

当前 Step 3A 使用 `BAAI/bge-small-zh-v1.5` 本地向量余弦相似度（85%）与标签 Jaccard（15%）跨链路召回 Top 6。模型可通过 `EFFECT_AGENT_EMBEDDING_MODEL` 指向本地目录或其他兼容模型。
