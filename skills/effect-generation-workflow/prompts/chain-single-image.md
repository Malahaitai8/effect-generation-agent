# Step 6: 单图驱动执行与 Prompt 模板

## 类型定义

最终视频生成模型接收一张首帧或单张输入图。前置步骤可以包含多次生图或多张参考图，不影响类型判断。

## 模板需要细化的内容

- 适用与退出条件
- 必需和可选输入
- 首帧规划与检查
- 前置生图节点及 Prompt 模块
- 单图生视频节点及 Prompt 模块
- 模型特定写法和参数约束
- 一致性、风险和验收规则

## 基础 Prompt 模块

生图：主体与保持项 → 外观/姿态 → 场景 → 构图/景别 → 风格/光影 → 质量 → 禁止项。

生视频：初始状态 → 动作时序 → 视觉变化 → 镜头 → 结束状态 → 一致性 → 禁止项。

具体规则和 few-shot 将按实施顺序第 2–4 步从代表案例中补齐。
