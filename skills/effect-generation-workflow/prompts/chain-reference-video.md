# Step 6: 参考视频驱动执行与 Prompt 模板

## 类型定义

最终视频生成模型接收参考视频，通常还接收用户主体图或前置标准化主体图。

## 支持模式

- 主体图 + 参考视频直接生成/替换
- 前置生图标准化 + 参考视频生成/替换

## 模板需要细化的内容

- 适用与退出条件
- 参考视频角色：动作、节奏、表演、镜头或完整结构
- 用户主体与参考主体适配检查
- 是否需要前置生图
- 替换对象与继承信息
- 主体结构、一致性、遮挡和长时序风险
- 模型特定写法和验收规则

## 基础 Prompt 模块

替换对象 → 新主体来源 → 继承的动作/节奏/表演 → 保持的新主体特征 → 场景和非目标主体处理 → 结构与一致性约束 → 禁止项。

具体规则和 few-shot 将按实施顺序第 3–4 步从代表案例中补齐。
